## 📌 Project Overview

**Kisaan Rakshak** is an AI-powered agricultural assistant designed to help farmers quickly detect crop diseases and pests using image recognition.

Agriculture losses due to pests and diseases cost farmers billions every year. Kisaan Rakshak helps solve this problem by providing:

• AI based crop disease detection  
• Instant treatment suggestions  
• Weather based agricultural insights  
• Multilingual farmer friendly interface  
• Real-time analytics dashboard  

The platform works directly in the browser using **client-side AI inference**, making it accessible even in low-resource environments.

## 🚀 Key Features

### 🌿 AI Pest & Disease Detection
Upload a crop image and the system detects pests or diseases using a **TensorFlow.js model**.

### 🩺 Smart Remedies Engine
Provides:
- Organic treatment suggestions
- Chemical pesticide recommendations
- Preventive measures

### 🌍 Multilingual Support
Supports multiple languages including:
- English
- Hindi (हिंदी)

### 📊 Analytics Dashboard
Track:
- Scan history
- Disease trends
- Crop health statistics

### 📱 Progressive Web App
- Installable on mobile devices
- Works on low-power smartphones
- Optimized for field usage

### 🌗 Dark Mode
Dark theme optimized for low-light environments.

## 🧠 AI Model

Pipeline:

Image Upload → Preprocessing → TensorFlow Model → Prediction → Remedy Suggestions

Advantages:

• No server latency  
• Privacy preserving  
• Works offline after model load

## ⚙️ Installation & Setup

### Clone Repository

git clone https://github.com/yash8709/Kisaan_rakshak.git  
cd Kisaan_rakshak

### Install Dependencies

npm install --legacy-peer-deps

### Run Development Server

npm start

### Build Production Version

npm run build

## 🔐 Environment Variables

Create a `.env` file and add:
